## Key Development Principles

1. **Design Theme:** Premium Eco-Retreat (Natural greens, warm earthy browns, sand beige, Playfair Display headings, smooth micro-interactions).
2. **Architecture:** Pure Vite + Modular Vanilla CSS (`src/css/`) + ES Modules (`src/js/`).
3. **Data Source:** Centralized store in [`src/js/data.js`](file:///src/js/data.js).
4. **Verification:** Always execute `npm run build` after changes to verify zero Vite build errors.
5. **Deployment Strategy:** `main` branch for source development, `host` branch for static production distribution (`dist/`).
